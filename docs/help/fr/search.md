# Rechercher

Trouvez une note, une tâche ou une idée en quelques lettres, et allez-y directement.

## Trouver quelque chose

1. Appuyez sur **Ctrl+F**, ou **/** sur le tableau (ou cliquez sur **Rechercher** dans l’en-tête).
2. Tapez quelques lettres. Les notes, tâches et idées s’affichent, votre mot marqué.
3. **↑** / **↓** pour vous déplacer. **Entrée** va à la note et la fait briller ; sur une tâche ou une idée, le clavier du tableau se pose sur cette ligne (sa note se déplie si elle était pliée), et **↑** / **↓** continuent de là. **Échap** ferme.

**Chercher dans** : **Partout** ou **Cet espace**.

Les notes archivées ne sont pas cherchées : ouvrez les [Archives](archive.md) pour les voir.

## Chercher dans les paramètres

Dans les **Paramètres**, **Ctrl+F** cherche plutôt parmi les réglages. Les mots en français et en anglais marchent (« sombre », « dark », « sauvegarde », « backup »). **Échap** efface la recherche, puis ferme les Paramètres.

## Changer la touche

**Ctrl+F** se change dans **Paramètres › Clavier** (**Changer**, puis appuyez sur les nouvelles touches). **/** marche toujours aussi, sauf dans Trier et les Archives (où **Ctrl+F** ouvre quand même la recherche).
